## Caveats

**`access-queries.sql` drops JOIN predicates and `GROUP BY`.** mdbtools reconstructs
`SELECT` / `FROM` / `WHERE` / `ORDER BY` but not join conditions, so every query reads as a
cross join. The real joins follow the FK chain:

```
tblPerformance → tblPortfolio → tblAccountOwner
                             → tblPortfolioType
tblPerformance → tblYear
```

Read the output as *intent*, not as runnable SQL.

**Form/report layouts and VBA source are not recoverable here.** They live in
`MSysAccessStorage` as compressed blobs fragmented across Access pages. `olevba` rejects
`.accdb`; carving the single embedded OLE header fails on incomplete sectors. Only the
object *names* survive, in `access-objects.csv`.

This is largely moot — the database contains exactly one standard module (`abjMouseWheel`,
a third-party mouse-wheel utility), so essentially all logic lives in the saved queries and
form bindings rather than in code.

**`access-objects.csv` is latin-1, not UTF-8** — the `Owner` column holds raw binary SIDs.
Read it with `encoding='latin-1'`.
